## US-06：管理服务 Token

### 使用场景

管理员进入「安全策略」Tab，为 MCP 服务生成多个 Token（命名区分用途），管理 Token 的启停。Token 用于 MCP Client 接入时认证。

### 交互流程

```
安全策略 Tab
  ├─ Token 列表
  │    ├─ 列：名称、状态（启用/停用）、创建时间、操作（启用禁用/删除）
  │    └─ [生成 Token] 按钮
  │
  └─ 生成 Token：
       ├─ 输入名称（如「生产环境」「开发测试」）
       ├─ [确认生成]
       └─ 弹窗展示 Token 明文
            ├─ 提示「请立即复制并妥善保存，关闭后无法再次查看」
            ├─ Token 文本（只读 + [复制] 按钮）
            └─ [关闭]
```

### 异常与边界

- 停用 Token：即时生效，使用该 Token 的 MCP Client 下次调用返回认证失败
- 删除 Token：确认弹窗，提示「删除后使用该 Token 的 MCP Client 将无法接入」
- 所有 Token 都被停用/删除：服务仍可发布，但外部 Client 无法调用（相当于服务空转）

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services/{id}/tokens` | 生成 Token。Body: `{ name }`。返回 `{ id, name, token }`（token 为明文，仅此一次） |
| `GET` | `/v1/mcp-services/{id}/tokens` | 查询 Token 列表（不暴露明文） |
| `DELETE` | `/v1/mcp-services/{id}/tokens/{tokenId}` | 删除 Token |
| `PUT` | `/v1/mcp-services/{id}/tokens/{tokenId}/toggle` | 启用/停用 |

Token 生成：随机字符串（如 32 位），存储前加密（`EncryptionUtils`）。

### 前端设计

- Token 列表：明文不展示，仅显示名称、状态、创建时间
- 生成 Token 弹窗：关键步骤，需要强调「仅此一次可见」，复制按钮显著

### 数据库设计

**`mcp_token` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id |
| `name` | VARCHAR(255) | Token 名称（用户命名） |
| `token` | VARCHAR(500) | 加密后的 Token 值 |
| `enabled` | BOOLEAN | 是否启用 |
| 审计字段 | — | 继承 BasePO |

索引：`(service_id)`，`UNIQUE(token)`

### 安全设计

- Token 生成后仅返回一次明文，后续查询不暴露
- Token 加密存储（复用 `EncryptionUtils`）
- MCP Client 请求通过 `Authorization: Bearer <token>` 传递，校验时解密比对
- 同一 Token 可用于多次请求，无过期时间（V1）

### 验收标准

1. 输入名称点击生成，弹窗展示 Token 明文，复制按钮可复制
2. 关闭弹窗后，Token 列表只显示名称，不显示明文
3. 停用 Token，状态变为停用
4. 删除 Token，确认后列表不再显示
