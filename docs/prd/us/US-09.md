## US-09：查看服务调用日志

### 使用场景

管理员进入「调用日志」Tab，查看外部 MCP Client 对该服务的调用记录：按时间、Tool、状态筛选，查看每次调用的详细信息。

### 交互流程

```
调用日志 Tab
  ├─ 筛选栏：
  │    ├─ 时间范围选择器（默认最近 7 天）
  │    ├─ Tool 下拉筛选（全部 / 各 Tool 名称）
  │    └─ 状态筛选（全部 / 成功 / 失败）
  │
  ├─ 日志列表（分页）：
  │    ├─ 列：时间、Tool 名称、SQL 类型标签、成功/失败标签、耗时(ms)、调用来源
  │    └─ 每行可展开 / 点击进入详情
  │
  └─ 日志详情（弹窗或展开行）：
       ├─ 基本信息：服务名、Tool 名、调用时间、调用来源
       ├─ 输入参数摘要
       ├─ SQL 完整文本
       ├─ 执行结果：成功 → 返回行数；失败 → 错误信息
       └─ 耗时
```

### 异常与边界

- 无日志时：空状态提示「暂无调用记录」
- 日志量大：分页加载，默认每页 20 条
- 时间范围过大：后端限制最大查询跨度（如 90 天）
- 服务被删除后：日志级联删除，无法再查询

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/v1/mcp-services/{id}/audit-logs` | 分页查询。Query: `page, size, toolName?, success?, startTime?, endTime?`。返回 `PageResponse<AuditLogVO>` |
| `GET` | `/v1/mcp-services/{id}/audit-logs/{logId}` | 查询日志详情 |

### 前端设计

- 日志列表为标准表格，成功/失败用绿色/红色标签
- 时间列格式化为相对时间（如「3 分钟前」）+ hover 显示精确时间
- SQL 文本截断显示（单行省略），详情中完整展示
- 支持简单的分页跳转

### 数据库设计

**`mcp_audit_log` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id（级联删除） |
| `tool_name` | VARCHAR(128) | Tool 名称 |
| `call_time` | DATETIME | 调用时间 |
| `caller_ip` | VARCHAR(45) | Client IP |
| `caller_client_name` | VARCHAR(255) | MCP Client 的 clientInfo.name |
| `principal_type` | VARCHAR(20) | SERVICE（V1） |
| `principal_id` | VARCHAR(255) | Token ID |
| `input_summary` | TEXT | 输入参数摘要（JSON） |
| `sql_text` | TEXT | 完整 SQL |
| `sql_op_type` | VARCHAR(20) | SELECT / INSERT / UPDATE / DELETE / DDL / OTHER |
| `success` | BOOLEAN | 是否成功 |
| `duration_ms` | BIGINT | 耗时（毫秒） |
| `row_count` | INT | 返回/影响行数 |
| `error_msg` | TEXT | 错误信息 |

索引：`(service_id, call_time)`，`(service_id, tool_name, call_time)`，`(call_time)`

### 安全设计

- 日志仅管理员可查看
- 不记录完整 Token 明文（只记录 Token ID）
- 是否记录完整 SQL 可配置（见 US-03 权限配置的扩展）

### 验收标准

1. 外部 MCP Client 调用 Tool 后，日志页出现对应记录
2. 按 Tool 名称筛选，只显示该 Tool 的调用记录
3. 按时间范围筛选，只显示范围内的记录
4. 点击某条日志，弹窗展示完整 SQL 和错误信息
5. 删除服务后，该服务的日志不再可查询
