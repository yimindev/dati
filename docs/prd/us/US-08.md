## US-08：发布与停用 MCP 服务

### 使用场景

管理员完成 Tool / Resource / Prompt 配置后，在「调试发布」Tab 预览能力列表，校验配置后发布服务。发布后获得 endpoint，可复制给 MCP Client 使用。支持停用和重新启用。

已发布服务如修改配置（Tool/Resource/Prompt/数据范围），线上继续服务旧版本，修改保存到草稿副本，需重新发布才覆盖。

### 交互流程

```
调试发布 Tab（发布前）
  ├─ 能力预览区：
  │    ├─ Tools 列表（name / type / 启用状态）
  │    ├─ Resources 列表（name / URI / 启用状态）
  │    ├─ Prompts 列表（name / 参数数 / 启用状态）
  │    └─ 如果某类能力为空，显示「暂未配置」
  │
  ├─ [发布] 按钮
  │    └─ 弹窗确认「发布后变更将对外生效，MCP endpoint 为 /{serviceId}/mcp」
  │    └─ 确认 → 发布成功 → 展示接入信息区
  │
  └─ 接入信息区（发布后展示）：
       ├─ MCP Endpoint：完整 URL（复制按钮）
       └─ 「服务运行中」状态标识

调试发布 Tab（已发布后，有未发布变更时）
  ├─ 顶部提示条：「有未发布的变更（编辑了 X 个 Tool / Y 个 Resource / ...）」
  ├─ 能力预览区显示草稿版本
  ├─ [发布变更] 按钮 → 确认 → 覆盖已发布快照
  └─ 接入信息区仍显示当前线上版本信息

调试发布 Tab（已发布，无变更时）
  ├─ 能力预览区显示已发布版本
  ├─ [停用] 按钮 → 确认「停用后 MCP endpoint 将返回错误」
  └─ 接入信息区

调试发布 Tab（已停用）
  ├─ [启用] 按钮 → URL 不变，恢复服务
```

### 异常与边界

- 发布前无任何 Tool/Resource/Prompt：允许发布（纯空服务）
- 发布后无启用状态的 Tool：MCP Client 的 tools/list 返回空数组
- 停用后 MCP Client 调用：MCP endpoint 返回明确错误（JSON-RPC error + HTTP 503）
- 启用后：需点击发布才恢复对外服务（停用状态不能直接用）
- 编辑 → 草稿 → 未发布就离开：草稿自动保存，下次进入时恢复

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services/{id}/publish` | 发布服务。生成/更新已发布快照，状态变更为 PUBLISHED |
| `POST` | `/v1/mcp-services/{id}/disable` | 停用服务。状态变更为 DISABLED |
| `POST` | `/v1/mcp-services/{id}/enable` | 启用服务。状态变更为 PUBLISHED |
| `GET` | `/v1/mcp-services/{id}/debug/tools` | 预览草稿 tools/list |
| `GET` | `/v1/mcp-services/{id}/debug/resources` | 预览草稿 resources/list |
| `GET` | `/v1/mcp-services/{id}/debug/prompts` | 预览草稿 prompts/list |
| `GET` | `/v1/mcp-services/{id}/diff` | 查询已发布 vs 草稿的差异摘要（哪些 Tool/Resource/Prompt 有变更） |

### 前端设计

- 调试发布 Tab 是信息聚合页，展示状态 + 能力预览 + 接入信息
- 三个能力预览区用 Tab 或折叠面板
- 「有未发布的变更」用黄色提示条
- 接入信息区用绿色底色卡片，复制按钮显著
- 配置示例用代码块展示

### 数据库设计

已发布快照方案（二选一，待详细设计确定）：

- **方案 A（单表 + 版本字段）**：mcp_tool / mcp_resource / mcp_prompt 增加 `version` 字段，发布时把 `version=draft` 的记录改为 `version=published`，同时保留旧发布版本
- **方案 B（快照表）**：独立的 `mcp_service_snapshot` 表，发布时将 Tool/Resource/Prompt 配置序列化为 JSON 存入，MCP endpoint 读取快照表。草稿仍读原表

两种方案对 US 描述无影响，验收标准相同。

### 安全设计

- 发布/停用/启用仅管理员可操作
- 发布操作记录操作人和时间
- MCP endpoint 仅读取已发布快照，不直接访问草稿数据

### 验收标准

1. 配置 Tool 后，在调试发布页看到 Tool 列表预览
2. 点击发布，状态变为「已发布」，展示 endpoint URL 和接入信息
3. 复制 endpoint URL，用外部 MCP Client 连接成功，tools/list 返回已启用 Tool
4. 修改 Tool 配置后保存，调试发布页出现「有未发布的变更」提示
5. 外部 MCP Client 仍看到旧版本 Tool（线上不受影响）
6. 点击发布变更，外部 MCP Client 看到新版本 Tool
7. 停用服务，外部 MCP Client 调用返回错误
8. 启用服务后发布，外部 MCP Client 恢复可用
