## US-05：创建与配置 Prompt

### 使用场景

管理员进入「Prompts」Tab，编写 Prompt 模板文本（使用 `{{paramName}}` 占位），定义参数列表。Prompt 暴露给 MCP Client 后，Client 可通过 `prompts/get` 获取替换后的文本。

### 交互流程

```
Prompts Tab
  ├─ Prompt 列表
  │    ├─ 列：name、参数数量、启用开关、操作（编辑/测试/删除）
  │    └─ [新建 Prompt] 按钮
  │
  └─ 编辑表单：
       ├─ name（文本框，必填）
       ├─ description（文本框，可选）
       ├─ content（Textarea）—— 支持 {{paramName}} 语法，等宽字体
       ├─ 参数列表（动态表格）：
       │    ├─ 列：参数名 / 描述 / 必填（复选框）
       │    └─ [+ 添加参数] [删除]
       ├─ [测试渲染] 按钮 → 见下
       └─ [保存]
```

测试渲染流程：

```
点击 [测试渲染] → 弹窗
  ├─ 自动解析 content 中的 {{paramName}}，生成输入表单
  ├─ 用户填入参数值
  ├─ [渲染] → 下方展示替换后的文本
  └─ 关闭
```

### 异常与边界

- content 中 `{{xxx}}` 与参数列表不一致：测试渲染时提示「参数 `xxx` 未定义」或「参数 `yyy` 在模板中未使用」
- name 为空：前端校验必填
- name 重复：保存时后端校验，返回「Prompt 名称已被使用」
- 删除 Prompt：确认弹窗

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services/{id}/prompts` | 创建 Prompt |
| `PUT` | `/v1/mcp-services/{id}/prompts/{promptId}` | 编辑 Prompt |
| `DELETE` | `/v1/mcp-services/{id}/prompts/{promptId}` | 删除 Prompt |
| `GET` | `/v1/mcp-services/{id}/prompts` | 查询 Prompt 列表 |
| `PUT` | `/v1/mcp-services/{id}/prompts/{promptId}/toggle` | 启用/禁用 |
| `POST` | `/v1/mcp-services/{id}/prompts/{promptId}/test-render` | 测试渲染。Body: `{ arguments: { paramName: value } }`。返回 `{ rendered: "..." }` |

### 前端设计

- content 编辑区支持 `{{paramName}}` 的高亮显示（与普通文本颜色不同）
- 参数列表为小型内联表格，操作简单
- 测试渲染弹窗自动根据 content 中的占位符生成输入框
- 参数列表变更时，content 编辑器旁的占位符提示同步更新

### 数据库设计

**`mcp_prompt` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id |
| `name` | VARCHAR(255) | Prompt 名称 |
| `description` | VARCHAR(500) | 描述（可选） |
| `content` | TEXT | Prompt 文本模板 |
| `arguments` | TEXT(JSON) | 参数列表 JSON：`[{name, description, required}]` |
| `enabled` | BOOLEAN | 是否启用 |
| 审计字段 | — | 继承 BasePO |

索引：`(service_id)`

### 安全设计

- Prompt 文本不做注入检测（MCP Client 侧负责安全使用）
- 测试渲染时参数值做基本的字符串转义

### 验收标准

1. 创建 Prompt，content 写「请分析 {{table}} 表的数据」，添加参数 `table`（必填），保存成功
2. 测试渲染，输入 table=tasks，渲染结果中 `{{table}}` 被替换为 `tasks`
3. content 中出现未定义参数名时，测试渲染提示「参数未定义」
4. 删除 Prompt 后列表不再显示
