## US-03：创建与配置 Tool

### 使用场景

管理员进入「Tools」Tab，创建四种类型的 Tool（SEARCH_METADATA / GET_TABLE_INFO / EXECUTE_SQL / PARAMETERIZED_SQL），配置名称、描述、输入参数、权限、执行限制。系统根据权限自动生成 annotations。

### 交互流程

```
Tools Tab
  ├─ Tool 列表
  │    ├─ 列：名称、类型标签、启用开关、操作（编辑/删除/测试）
  │    └─ [新建 Tool] 下拉按钮 → 选择 Tool 类型 → 弹出编辑表单
  │
  └─ 编辑表单（按类型展示不同字段）：
       ├─ 通用配置：
       │    ├─ name（校验格式 + 唯一性）
       │    ├─ title（可选）
       │    ├─ description（必填，帮助 LLM 理解用途）
       │    └─ 启用开关
       │
       ├─ 输入参数 Schema 编辑器：
       │    ├─ 结构化模式：添加字段 → 字段名/类型/必填/描述
       │    └─ Raw 模式：直接编辑 JSON Schema 文本（两模式互切）
       │
       ├─ 类型专属配置：
       │    ├─ SEARCH_METADATA / GET_TABLE_INFO / EXECUTE_SQL：无额外配置
       │    └─ PARAMETERIZED_SQL：
       │         ├─ SQL 模板编辑器（Textarea，语法高亮）
       │         ├─ 绑定数据源（下拉选择）
       │         └─ 参数列表编辑器：每行 [name/类型/必填/默认值/描述]
       │
       ├─ 权限配置（仅 EXECUTE_SQL 和 PARAMETERIZED_SQL）：
       │    ├─ 复选框组：SELECT / INSERT / UPDATE / DELETE / DDL / 多语句
       │    │   └─ SELECT 默认勾选，其余默认不勾选
       │    ├─ 最大返回行数（数字输入）
       │    ├─ 超时时间（秒，数字输入）
       │    └─ 是否需要确认（开关，写操作建议开启）
       │
       └─ Annotations 预览（只读）：
            └─ 自动计算展示：readOnlyHint / destructiveHint / idempotentHint

调试测试：在 Tool 列表中点击 [测试] → 见 US-07
```

### 异常与边界

- name 格式不合法：实时校验提示「仅允许 A-Z, a-z, 0-9, _, -, .，1-128 字符」
- name 重复：保存时后端校验，返回「Tool 名称已被使用」
- inputSchema 非法 JSON Schema：Raw 模式下保存时校验，不合法则报错定位行号
- 权限配置与 annotations 映射：不合法组合不阻止，但 annotations 按规则如实反映
- PARAMETERIZED_SQL 的 SQL 模板语法错误：保存时不做语法校验（不同数据库方言不同），执行时报错
- PARAMETERIZED_SQL 参数名未在 SQL 中引用：保存时前端 warning 提示（非阻止）
- 删除 Tool：确认弹窗，提示「删除后 MCP Client 将无法调用此工具」
- 已发布服务修改 Tool：保存到草稿副本，需重新发布

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services/{id}/tools` | 创建 Tool |
| `PUT` | `/v1/mcp-services/{id}/tools/{toolId}` | 编辑 Tool |
| `DELETE` | `/v1/mcp-services/{id}/tools/{toolId}` | 删除 Tool |
| `GET` | `/v1/mcp-services/{id}/tools` | 查询 Tool 列表（含 annotations 预览） |
| `PUT` | `/v1/mcp-services/{id}/tools/{toolId}/toggle` | 启用/禁用 |

Tool 实体核心字段：
```
{ name, title?, description, enabled, toolType, inputSchema(JSON), execConfig(JSON),
  permConfig(JSON), confirmRequired, timeout, maxRows }
```

execConfig 结构（按类型不同）：
- SEARCH_METADATA / GET_TABLE_INFO / EXECUTE_SQL：`{}`
- PARAMETERIZED_SQL：`{ dataSourceId, sqlTemplate, parameters: [{name,type,required,defaultValue,description}] }`

permConfig 结构：`{ allowSelect, allowInsert, allowUpdate, allowDelete, allowDdl, allowMulti }`

### 前端设计

- 新建 Tool 按钮为下拉按钮（Dropdown Button），四个选项对应四种 Tool 类型
- Tool 编辑表单较长，可用分段折叠面板（通用 → 参数 → 权限）
- SQL 模板编辑器：等宽字体、语法无高亮（V1），行号可选
- Annotations 预览区域为灰色只读卡片
- Tool 列表中的启用开关即时生效（不弹确认）

### 数据库设计

**`mcp_tool` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id |
| `name` | VARCHAR(128) | Tool 唯一标识 |
| `title` | VARCHAR(255) | 显示名（可选） |
| `description` | TEXT | 功能描述 |
| `enabled` | BOOLEAN | 是否启用 |
| `tool_type` | VARCHAR(30) | SEARCH_METADATA / GET_TABLE_INFO / EXECUTE_SQL / PARAMETERIZED_SQL |
| `input_schema` | TEXT(JSON) | JSON Schema 文本 |
| `exec_config` | TEXT(JSON) | 执行配置（按类型不同） |
| `perm_config` | TEXT(JSON) | 权限配置 |
| `confirm_required` | BOOLEAN | 是否需要确认 |
| `timeout` | INT | 超时秒数 |
| `max_rows` | INT | 最大返回行数 |
| 审计字段 | — | 继承 BasePO |

索引：`UNIQUE(service_id, name)`，`(service_id)`

### 安全设计

- Tool 只能操作当前服务数据范围内的数据源和表（由执行引擎保证，此处不做配置层校验）
- PARAMETERIZED_SQL 的 SQL 模板不在此处校验权限（执行时才校验）

### 验收标准

1. 创建 SEARCH_METADATA 类型 Tool，name 格式不合法时实时提示
2. 创建 PARAMETERIZED_SQL 类型 Tool，配置 SQL 模板和参数列表，保存成功
3. 权限配置选择 SELECT + INSERT，annotations 预览显示 `readOnlyHint: false, destructiveHint: true`
4. 创建同名 Tool 时报错「Tool 名称已被使用」
5. 切换启用开关，Tool 列表即时更新
6. 删除 Tool，确认弹窗展示后执行，列表不再显示
