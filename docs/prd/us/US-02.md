## US-02：配置数据访问范围

### 使用场景

管理员进入 MCP 服务详情页的「数据范围」Tab，为服务选择可访问的数据源、表、主题。配置后，Tool 的元数据检索和 SQL 执行都受此范围约束。

### 交互流程

```
数据范围 Tab
  ├─ 添加方式选择器（下拉按钮）：
  │    ├─ [+ 添加数据源] → 下拉列表选择数据源（从已有 DataSource 列表获取）
  │    ├─ [+ 添加表] → 弹出树形选择器（数据源 > 表，重名表显示 dsName/tableName）
  │    └─ [+ 添加主题] → 下拉列表选择主题（从已有 Subject 列表获取）
  │
  ├─ 已选范围列表：
  │    ├─ 每项显示：类型图标 + 名称 + [删除]
  │    ├─ 数据源项：图标+"数据源名称"
  │    ├─ 表项：图标+"dsName / tableName"
  │    └─ 主题项：图标+"主题名称" + 「引用模式，自动同步」提示
  │
  └─ [保存] 按钮
       └─ 保存时校验：直接选的表如被 Tool 引用则不允许移除，弹提示
```

### 异常与边界

- 选的数据源后来被删了：保存时不校验数据源是否存在（引用可能失效），执行 Tool 时再报错
- 主题引用自动同步：主题增删表，服务范围自动变化，不需要管理员重新保存
- 重复添加：不阻止（前端可做提示但非强制）
- 已发布服务修改数据范围：保存到草稿副本，需重新发布才生效（见 US-08）
- 直接选的表被 Tool 引用时点删除：前端按钮置灰，hover 提示「该表被 Tool [xxx] 引用，请先在 Tool 配置中解除」

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `PUT` | `/v1/mcp-services/{id}/data-scope` | 全量替换保存。Body: `{ items: [{ type, referenceId, referenceName, dataSourceId?, dataSourceName? }] }`。返回 `IdResponse` |
| `GET` | `/v1/mcp-services/{id}/data-scope` | 查询当前数据范围。返回 `{ items: [...] }`。主题类型额外返回展开的表列表（仅用于前端展示） |
| `GET` | `/v1/mcp-services/{id}/data-scope/tool-relations` | 查询直接选的表中有哪些被 Tool 引用。返回 `{ tableId: [toolName, ...] }`。用于前端置灰删除按钮 |
| `GET` | `/v1/data-sources?type=scope_selector` | 可选数据源列表（复用 DataSourceController） |
| `GET` | `/v1/data-sources/{dsId}/tables` | 数据源下表列表（带数据源名前缀） |
| `GET` | `/v1/subjects?type=scope_selector` | 可选主题列表（复用 SubjectController） |

### 前端设计

- 三种添加方式用一个下拉按钮（Split Button），默认展示常用添加方式
- 树形选表器：第一层数据源名，展开后第二层为表列表。重名表显示 `dsName / tableName`
- 已选范围列表：区分三种类型的视觉展示（不同图标 + 不同颜色标签）
- 主题项 hover 展示「主题内的表：table_a, table_b, ...」
- 保存时如果移除被引用的表，弹 toast 提示具体 Tool 名称

### 数据库设计

**`mcp_service_data_scope` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id |
| `scope_type` | VARCHAR(20) | DATA_SOURCE / TABLE / SUBJECT |
| `reference_id` | VARCHAR(255) | 数据源 ID / 表 ID / 主题 ID |
| `reference_name` | VARCHAR(255) | 冗余名称，用于展示 |
| `data_source_id` | VARCHAR(255) | scope_type=TABLE 时有值，表所属数据源 ID |
| `data_source_name` | VARCHAR(255) | scope_type=TABLE 时有值 |

索引：`(service_id)`

### 安全设计

- 通过服务 ID 校验操作权限（属于当前租户/用户）
- 数据源列表和主题列表复用已有接口的权限过滤

### 验收标准

1. 添加数据源后，已选列表展示数据源名称
2. 添加表时，树形选择器展示数据源 > 表结构，重名表带前缀
3. 添加主题后，已选列表展示主题名 + 引用模式说明
4. 保存后，再次进入范围 Tab 看到之前的选择
5. 直接选的表被 Tool 引用时，删除按钮置灰且有提示
6. 主题引用后，在 DatI 中修改了主题关联的表，MCP 服务的数据范围自动更新
