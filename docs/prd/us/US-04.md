## US-04：创建与配置 Resource

### 使用场景

管理员进入「Resources」Tab，编辑「示例 SQL」Resource 的 URI 和内容，查看系统自动生成的「权限说明」Resource。

### 交互流程

```
Resources Tab
  ├─ Resource 列表
  │    ├─ 示例 SQL：name / URI / 启用开关 / [编辑] [预览] [删除]
  │    └─ 权限说明：name / URI / 启用开关 / [预览]（标记「系统生成·只读」，无编辑/删除按钮）
  │
  └─ 编辑示例 SQL（表单）：
       ├─ URI（文本框，默认值 dati://services/{serviceId}/examples，可改）
       ├─ name（文本框）
       ├─ content（Textarea）—— 用户手写的 SQL 示例文本
       └─ [保存]
```

### 异常与边界

- 示例 SQL 的 URI 为空：前端校验必填
- 「权限说明」由系统根据当前 Tool 的权限配置自动生成纯文本说明，随 Tool 配置变化实时更新
- 删除示例 SQL Resource → 弹确认

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services/{id}/resources` | 创建 Resource（类型 EXAMPLES） |
| `PUT` | `/v1/mcp-services/{id}/resources/{resourceId}` | 编辑 Resource |
| `DELETE` | `/v1/mcp-services/{id}/resources/{resourceId}` | 删除 Resource |
| `GET` | `/v1/mcp-services/{id}/resources` | 查询 Resource 列表 |
| `PUT` | `/v1/mcp-services/{id}/resources/{resourceId}/toggle` | 启用/禁用 |

SQL_POLICY 类型的 Resource 由系统自动维护，不提供增删改接口。查询时动态生成 content：遍历所有 Tool 的权限配置，拼接为文本。

### 前端设计

- 列表页区分两种 Resource 的视觉风格：「权限说明」行灰色底色 + 标签「系统生成」
- 编辑示例 SQL：简单表单，无需复杂编辑器
- 预览 Resource：弹窗展示渲染后的文本内容

### 数据库设计

**`mcp_resource` 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键 |
| `service_id` | VARCHAR | FK → mcp_service.id |
| `uri` | VARCHAR(500) | Resource URI |
| `name` | VARCHAR(255) | 资源名称 |
| `description` | VARCHAR(500) | 描述（可选） |
| `resource_type` | VARCHAR(20) | EXAMPLES / SQL_POLICY |
| `content` | TEXT | 资源内容（EXAMPLES 用户写，SQL_POLICY 系统生成） |
| `enabled` | BOOLEAN | 是否启用 |
| 审计字段 | — | 继承 BasePO |

索引：`(service_id)`

### 安全设计

- EXAMPLES 内容由用户自行编辑，不做注入检测（纯文本展示）
- SQL_POLICY 为系统只读，前端不可编辑

### 验收标准

1. 编辑示例 SQL 的 URI 和内容，保存后列表展示
2. 权限说明 Resource 的 content 随 Tool 权限配置变化自动更新
3. 预览 Resource 弹窗展示内容
4. 删除示例 SQL 后，列表只剩权限说明
