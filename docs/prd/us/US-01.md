## US-01：创建与编辑 MCP 服务

### 使用场景

管理员进入 DatI 管理端，创建一个新的 MCP 服务，或编辑已有服务的基本信息（名称、描述）。在服务列表页查看、搜索、筛选所有 MCP 服务。

### 交互流程

```
服务列表页
  ├─ 搜索框（按名称模糊搜索）
  ├─ 状态筛选下拉（全部 / 草稿 / 已发布 / 已停用）
  ├─ 列表列：名称、描述（截断）、状态标签、Tool 数、endpoint 路径、更新时间
  ├─ 行操作：详情 / 删除（US-10）；行点击进详情页。无独立编辑按钮（编辑统一在详情页）
  └─ [新建服务] 按钮 → 弹出对话框（基本信息 + 数据范围，数据范围必填）→ 提交 → 刷新列表

服务详情页（左侧导航 Tab：基础信息 / 数据范围 / Tools / Resources / Prompts / 调试发布 / 调用日志）
  └─ 基础信息 Tab：
       ├─ 名称、描述可编辑
       ├─ 状态标签展示（草稿 / 已发布 / 已停用）
       ├─ endpoint 完整 URL（已发布后展示，带复制按钮）
       └─ 操作按钮：发布 / 停用 / 启用 / 删除（按状态动态显示）
```

### 异常与边界

- 名称重复：不校验（名称非唯一标识），允许重名
- 名称为空：保存时前端校验，必填
- **数据范围为必填**：创建请求必须携带 `data_scopes`（缺失/空列表由 bean validation 拦截，返回通用 400；服务层 `MS018` 为内部调用兜底）；发布时数据范围为空 → MS019 400（见 US-08）
- 删除服务：需跳转到 US-10（删除确认流程）
- 停用/启用：见 US-08
- 已删除服务的 ID 不可复用

### 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/v1/mcp-services` | 创建服务。Body: `{ code, name, description, data_scopes: [...] }`（`data_scopes` 必填非空，事务内创建服务与数据范围）。返回 `IdResponse` |
| `PUT` | `/v1/mcp-services/{id}` | 编辑基本信息。Body: `{ name, description }`。返回 `IdResponse` |
| `GET` | `/v1/mcp-services` | 分页列表。Query: `page, size, keyword?, status?`。返回 `PageResponse<McpServiceVO>` |
| `GET` | `/v1/mcp-services/{id}` | 查询详情。返回 `McpServiceVO`（含 endpoint 完整 URL） |

### 前端设计

- 服务列表页：路由 `/mcp-services`，标准分页表格
- 服务详情页：路由 `/mcp-services/:id`，左侧导航 Tab 布局。基础信息 Tab 为默认 Tab
- 新建服务对话框：Modal 弹窗，基本信息（服务标识/名称/描述）+ 数据范围区块（必填，选择器与详情页「数据范围」Tab 共用），名称必填
- endpoint URL 展示：拼接当前域名前缀，旁有复制按钮
- 状态标签：草稿（灰色）、已发布（绿色）、已停用（红色）

### 数据库设计

**`mcp_service` 表**（继承 `BasePO` 字段：`id`、`createdBy`、`createdAt`、`updatedBy`、`updatedAt`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | VARCHAR | 主键，系统生成 |
| `name` | VARCHAR(255) | 服务名称 |
| `description` | TEXT | 服务描述 |
| `status` | VARCHAR(20) | DRAFT / PUBLISHED / DISABLED |
| `endpoint_path` | VARCHAR(255) | 发布后生成，格式 `/{id}/mcp` |

> 注：已发布快照存储方案见 US-08。服务删除为硬删除，级联删除子表。

### 安全设计

- 仅登录管理员可访问
- 创建/编辑时，`createdBy`/`updatedBy` 从 `RequestContext` 注入
- 删除操作需经 US-10 流程确认

### 验收标准

1. 输入名称和描述，点击新建，服务出现在列表页，状态为「草稿」
2. 列表页按名称搜索返回匹配结果，按状态筛选只显示对应状态的服务
3. 编辑名称和描述（详情页基础信息 Tab）后保存，列表页反映更新
4. 详情页默认显示基础信息 Tab，已发布服务展示 endpoint 完整 URL，点击复制按钮复制成功
