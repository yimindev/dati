## 依赖关系图

```
US-01 ───────────────────────────────────────────┐
  │                                               │
  ├── US-02 ──────────────────────┐                │
  │    │                          │                │
  │    ├── US-03 ────────┐        │                │
  │    │    │            │        │                │
  │    │    ├── US-07    │        │                │
  │    │    │            │        │                │
  │    │    └── US-08 ───┤        │                │
  │    │         │       │        │                │
  │    │         └── US-09       │                │
  │    │                         │                │
  │    ├── US-04 ────────────────┤                │
  │    │                         │                │
  │    └── US-05 ────────────────┤                │
  │                              │                │
  ├── US-06 ─────────────────────┘                │
  │                                               │
  └── US-10 ──────────────────────────────────────┘
```

- US-01 是基础，其余故事都依赖它
- US-02（数据范围）被 US-03（Tool）依赖
- US-07（调试）依赖 US-03
- US-08（发布）依赖 US-03 + US-06（至少可发布的 Tool 和 Token）
- US-09（日志）依赖 US-08（发布后才有外部调用日志）
- US-10（删除）依赖 US-01 即可，但展示级联影响清单时需查询所有子资源
