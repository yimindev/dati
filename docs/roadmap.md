# 路线图（Roadmap）

本文件包含项目阶段性目标与里程碑规划。以下为示例骨架，具体内容请结合产品与技术规划补充。

## 里程碑

### M1 基础能力（0.1.x）
- 后端：数据源连接、元数据探查（catalog/schema/table/column）
- 前端：基础管理界面，数据源 CRUD
- 文档：README、开发与部署、API 草案

### M2 语义检索（0.2.x）
- 语义实体与索引结构完善
- 简单检索 API 与前端检索界面
- 首批性能优化与监控

### M3 数据可视化与权限（0.3.x）
- 数据查询与可视化组件
- 权限与审计（尤其是执行 SQL 接口）
- 部署与运维方案完善（日志、指标、报警）

## 待办（Backlog 示例）
- [ ] 集成 OpenAPI（Springdoc）自动生成 API 文档
- [ ] 前端引入 Vitest，完善单元测试
- [ ] 多数据库 Profile 示例（MySQL、PostgreSQL）与 CI 验证
- [ ] 数据导入/导出能力评估
- [ ] 语义检索向量化服务对接方案评估

## 发布节奏（建议）
- 小步快跑，每 2-3 周发布一个补丁/小版本
- 变更记录维护在 `docs/changelog.md`
