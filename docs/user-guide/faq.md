# 常见问题

## 数据源连接

### Q: 连接测试失败怎么办？

1. 检查 JDBC 连接字符串是否正确
2. 确认数据库网络可达（如数据库在本地需使用 `host.docker.internal` 代替 `localhost`）
3. 验证用户名和密码是否正确
4. 确认数据库已开启远程访问权限

### Q: 支持哪些数据库？

目前支持 MySQL、PostgreSQL、H2。更多数据库支持持续添加中。

## MCP 服务

### Q: 发布后可以修改吗？

已发布的服务修改后会生成草稿副本，原服务继续运行。修改完成后重新发布即可更新。

### Q: MCP 端点地址是什么格式？

```
http://your-domain/mcp/{服务标识}
```

例如服务标识为 `user-analysis`，则端点地址为：

```
http://your-domain/mcp/user-analysis
```

### Q: Tool 和 Prompt 的区别是什么？

| | Tool | Prompt |
|------|------|------|
| **用途** | 供 LLM 调用的数据查询接口 | 供 LLM 获取的上下文模板 |
| **输出** | SQL 执行结果 | 渲染后的文本 |
| **协议** | `tools/list`、`tools/call` | `prompts/get` |

## 模板语法

### Q: 模板渲染结果不对怎么办？

1. 使用 Tool 编辑器中的「测试渲染」按钮预览结果
2. 检查参数名称是否与模板中一致
3. 确认参数类型与 SQL 中的预期类型匹配

### Q: 如何调试复杂的条件模板？

建议将复杂模板拆分为多个简单的 Tool，分别测试每个条件分支的正确性。
