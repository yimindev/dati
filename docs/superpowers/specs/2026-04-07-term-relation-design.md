# 术语关联实体交互设计

**日期**: 2026-04-07
**状态**: 已批准

## 概述

优化术语管理（TermManager）组件中关联实体的交互，使其更加简洁清晰。

## 目标

1. 明确区分"表级关联"和"字段级关联"
2. 简化操作路径，减少点击次数
3. 已有关联一目了然，支持快速管理

## 设计方案

### 1. 术语列表展示（混合式）

| 术语名称 | 描述 | 已关联实体 | 操作 |
|---------|------|-----------|------|
| 客户 | 业务客户信息 | ● users ● orders +3 more | [管理] [编辑] |
| 营收 | 月度营收统计 | - | [管理] [编辑] |

- **已关联实体列**：最多显示 2 个关联标签，超出显示 `+n more`
- **操作列**：用**[管理]**按钮替代展开行，点击打开管理弹窗

### 2. 关联管理弹窗（弹窗分步式）

分两个步骤，用步骤条（Steps）指示：

**Step 1: 选择关联类型**
- 选项A: 📊 关联整个表 - 将术语与整张表关联
- 选项B: 📋 关联具体字段 - 将术语与表字段关联

**Step 2A (选择表)**:
- 表列表 + 搜索
- 多选框选择

**Step 2B (选择字段)**:
- 左右分栏：左侧表列表（可搜索），右侧选中表的字段（可搜索）
- 字段多选

**已有关联管理**:
- 弹窗顶部展示当前术语的所有已有关联
- 每个关联显示类型标签（表级/字段级）+ 目标 + 删除按钮
- 底部"添加新关联"按钮

## 组件变更

### TermManager.vue 改造

1. **表格列调整**：
   - 移除 expand-row-keys 展开机制
   - 新增"已关联实体"列（显示标签摘要）
   - 操作列新增"管理关联"按钮

2. **新增 RelationDialog 组件**（或合并到 TermManager）：
   - Step 步骤条
   - 类型选择卡片
   - 表选择器（单/多选 + 搜索）
   - 字段选择器（左右分栏 + 搜索）
   - 已有关联列表展示

## API 变更

无变更，保持现有 API 接口不变。

## 交互流程

```
1. 用户点击"管理"按钮
   ↓
2. 弹窗显示：Step 1 - 选择关联类型
   ↓
3A. 用户选择"表级" → Step 2A - 选择表
3B. 用户选择"字段级" → Step 2B - 选择字段
   ↓
4. 用户选择目标后点击"确认关联"
   ↓
5. API 调用 linkTermRelation
   ↓
6. 刷新已有关联列表
```
