# 术语管理 - 端到端测试

## TC-TERM-001 创建、查询、更新、删除术语
**级别：** P0
**前置：** 已登录，已创建主题

1. 创建一个主题
2. 在该主题下创建一个术语，填写名称、描述
3. 验证创建返回 200，包含 id
4. 查询该主题的术语列表，用默认分页参数
5. 验证列表分页信息合理：
   - `page`、`size`、`total`、`total_pages` 字段存在且数值合理
   - 不传 `page=0`（已知该值会导致 500），使用默认分页
6. 确认刚创建的术语在列表中，验证：
   - `name`、`description` 与创建时一致
   - `created_at`、`updated_at` 为合理时间戳
   - `created_by`、`updated_by` **不为 null**
7. 查询术语详情，验证与列表中一致
8. 仅更新该术语的 description（部分更新，不传其他字段）
9. 查询详情验证 description 已更新，其他字段未被意外修改
10. 删除该术语
11. 查询列表确认已删除
12. 删除主题（清理）

## TC-TERM-002 术语关联关系管理
**级别：** P1
**前置：** 已登录，已创建主题和术语

1. 创建一个主题和一个术语
2. 为该术语添加一个关系（relation），关联到某个表和字段
3. 验证添加成功返回 200
4. 查询术语详情，验证 relations 中包含刚添加的关联
5. 验证 relation 的 tableId 和 fieldName 与添加时一致
6. 删除该 relation
7. 查询术语详情，验证：
   - relation 已移除
   - `relations` 字段为 `[]`（空数组），**不是 null**

8. 删除术语和主题（清理）
