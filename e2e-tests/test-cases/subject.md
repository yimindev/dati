# 主题管理 - 端到端测试

## TC-SUBJ-001 创建、查询、更新、删除主题
**级别：** P0
**前置：** 已登录

1. 创建一个主题，填写名称和描述
2. 验证返回结果：
   - 包含 `id` 且为 UUID 格式
   - 状态码 200
3. 在主题列表中用默认分页参数查询该主题名称，确认能找到
4. 验证列表项完整合理：
   - `name`、`description` 与创建时一致
   - `created_at`、`updated_at` 为合理时间戳
   - `created_by`、`updated_by` **不为 null、不为空**
   - `created_user_name`、`updated_user_name` **不为 null、不为空**
5. 查询主题详情，验证与列表中一致
6. **仅更新 description**（部分更新，不传 name），验证返回 200 而非 500
7. 查询详情验证 description 已更新，`updated_at` 晚于 `created_at`，name 未被修改
8. 删除该主题（清理）
9. 查询列表确认已删除

## TC-SUBJ-002 为主题添加和删除表
**级别：** P1
**前置：** 已登录，已有数据源
**注意：** 需要真实数据库连接

1. 创建一个主题
2. 查询该主题的可用表列表（available-tables）
3. 验证返回的表列表非空，每个表包含 name 等基本信息
4. 选择一个表添加到主题中
5. 查询该主题的已添加表列表，确认刚添加的表在其中
6. 验证添加的表信息与 available-tables 中一致
7. 删除该表
8. 查询已添加表列表，确认已移除
9. 删除主题（清理）
